Professional Self-Assessment

Completing my Computer Science degree has helped me become more confident in learning technical concepts, solving problems, and turning ideas into working software. I have learned that development involves more than writing code that runs. It also requires testing, communication, careful decisions, and responsibility for the results.

My software engineering internship in the aerospace industry has given me experience with Python scripts, firmware testing, automated tests, log analysis, and development workflows. This work has shown me how important reliability, teamwork, and clear results are when software supports complex systems.

I also started Sunday Drive Games to continue developing games and growing my programming and creative skills. Building games has helped me combine programming, design, debugging, and feedback. My long-term goal is to continue growing as a software developer while building my independent game development work and maintaining time for my family.

Collaboration and Communication

My internship and game projects have taught me to consider other people's perspectives, explain my decisions, and use feedback to improve my work. Through code reviews, documentation, and this portfolio, I have practiced explaining not only what I changed, but why I changed it.

Algorithms and Computing Practices

My CS-300 Advising Assistance Program demonstrates how data structures and algorithms affect a solution. I added binary search alongside hash-table searching and compared their behavior through performance testing. This helped me understand the trade-offs between approaches and why measured performance depends on the data and test conditions.

Software Engineering and Data Integrity

I improved input handling and error reporting in my program and added course-data validation. My internship has also reinforced that security and integrity matter even when writing small scripts. Code can affect important data and decisions, so results need to be trustworthy. I believe it is important to speak up when something does not seem right, document concerns honestly, and take responsibility rather than ignore a problem.

Security Mindset

My code review taught me to look beyond basic functionality and consider weaknesses in design, input handling, and sensitive information. I understand that security should be considered throughout development, not added as an afterthought.

Together, my coursework, internship, and independent projects show my progress in collaboration, professional communication, algorithmic problem-solving, computing practices, and security. I see this portfolio as evidence of that progress and a foundation for continued growth.
